# Word Hour — версия с интервальным повторением

### Функции
- Карточки с четырьмя оценками: «Не знаю», «Тяжело», «Знаю», «Легко».
- Интервалы по умолчанию: 10 минут / 1 день / 3 дня / 7 дней. Далее интервалы адаптируются по SM-2-подобной схеме.
- Слова «Не знаю» возвращаются в конец текущей сессии после остальных карточек.
- Дневной лимит новых слов, пауза и возобновление сессии.
- Пять тренажёров: карточки, тест из 4 вариантов, ввод перевода, поиск пар, обратный перевод.
- Добавление, редактирование, одиночное и массовое удаление слов.
- Импорт CSV, TXT, JSON и XLSX; экспорт CSV и полной резервной копии JSON.
- Отдельное почасовое слово и Scriptable-виджет iPhone.

### Запуск и установка
Размести содержимое папки на HTTPS-хостинге (например, Netlify или GitHub Pages). Открой URL в Safari на iPhone → «Поделиться» → «На экран Домой».

### Импорт
CSV-заголовки: `word,translation,uk,transcription,pos,level,example,example_translation`. Минимум нужны `word` и `translation`. TXT: `слово | перевод`. XLSX использует SheetJS CDN при первом открытии импорта.

### Виджет iPhone
Установи Scriptable. В Word Hour → «Ещё» → «Виджет iPhone» скачай `words.json` и `WordHour-Widget.js`. Сохрани JSON в iCloud Drive/Scriptable/WordHour/words.json, создай Scriptable-скрипт из JS-файла, затем добавь Scriptable widget на экран «Домой» и выбери этот скрипт. Фактическую частоту обновления контролирует iOS.

### Хранение
Слова и прогресс хранятся в IndexedDB браузера на устройстве. Перед очисткой данных Safari экспортируй резервную копию JSON.
